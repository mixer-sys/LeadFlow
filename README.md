<h1 align="center">LeadFlow</h1>

<p align="center">A home for managing leads and tracking the path from first contact to opportunity.</p>

## About

LeadFlow is a lead-management application. Use this project to keep prospect information organized and make follow-up and pipeline progress easier to manage.

## Features

- Organize lead and prospect information.
- Track leads as they move through a sales pipeline.
- Keep follow-up activity and next steps in view.
